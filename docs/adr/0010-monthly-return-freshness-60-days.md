# ADR 0010 — 一、五、十年回報及基金規模採用 60 日 freshness

日期：2026-10-02
狀態：已接受（使用者批准）

## 決定

積金局基金平台的一年、五年、十年年化回報（以及同一批月度資料的基金規模），自官方 `dataAsOf` 起最多採用 **60 個日曆日**。第 60 日仍可列入排名；第 61 日起標為 stale 並從排名剔除。例：截至 2026-08-31 的資料有效至 2026-10-30。

三年回報維持 ADR 0007 的 90 日；基金現行狀態及基金概覽沿用各自政策。

## 原因

平台通常在月結後三至四星期才公布上月資料，經每週擷取、候選審核及人工發布後才上線。舊 45 日門檻令上一個月的資料在新一個月資料上線前已全數過期（例如 2026-08-31 資料於 2026-10-16 起過期，而 2026-09-30 資料預計 10 月下旬才公布），網站會出現一段沒有任何一年回報可排名的空窗。60 日覆蓋正常公布及發布時間，同時仍會在資料明顯落後時排除排名。

## 實作約束

- 只改 `packages/coverage/src/data-freshness.ts` 的 `MONTHLY_GRACE_DAYS`；新建 seed 將 `returnsGraceDays: 60` 凍結在 `provenance.freshnessPolicy`。
- API 的 `DEFAULT_RETURNS_GRACE_DAYS`（45）只是舊快照缺欄位時的備援，不修改，避免回溯改寫已發布判斷。
- 介面顯示 API 提供的寬限日數；說明文字同步改為 60 日。每行仍保留官方截至日期及來源。

## 否決方案

- **維持 45 日**：每月固定出現全數過期空窗。
- **取消過期判斷**：資料落後時仍排名，違反時效政策。

## 重審條件

若平台公布時間明顯改變，或連續兩個月在 60 日內仍未能上線新批次，重新檢視。
