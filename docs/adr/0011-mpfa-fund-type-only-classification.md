# ADR 0011 — 基金分類只用積金局基金類型

日期：2026-10-04
狀態：已接受（使用者指示「所有基金分類只根據 MPFA 劃分」，並選擇「全部非官方分類都移除」）
取代：ADR 0005（三桶資產歸類）；Lipper 比較組別（#194 起的 `lipperCategory` 口徑）

## 決定

網站唯一的基金分類是積金局強積金基金平台的「基金類型」。

1. 比較組別＝積金局中文基金類型原文，例如「股票基金 - 香港股票基金」「混合資產基金 - 61% 至 80% 股票」。排名、同組平均、篩選、圖表一律用這個口徑。
2. 對照表在 `packages/coverage/src/mpfa-fund-type.ts`：24 個類型，英文鍵逐字等於平台快照 `fundType`，中文取自平台中文版同一隻基金的「基金類型」欄，另記平台篩選的六個基金類別。2026-10-04 擷取時 451 隻基金類別逐隻對照，中英一對一。
3. `publication-seed` 斷言每個 `fundType` 都在清單內，任何一隻對不上就整份發布停下；不做模糊配對，亦不自行翻譯。API 對清單以外的類型回傳「積金局未提供基金類型」，這些基金不參與同組排名。
4. 移除 Lipper 分類（`lipperCategory`、`classification` 及其原始檔與對照表）、三桶資產歸類（`mappedAllocation`、`allocation-label-map.json`、組別三桶平均及解讀中的「股票配置」因素）。便覽配置仍以原文照錄顯示。
5. 受託人自述的 `fundTypeDescriptor`（例如「Equity Fund - Hong Kong」）只作參考顯示，不用作分組。

## 原因

使用者要求所有分類只跟積金局。Lipper 是非官方商業分類，三桶是本站編輯判斷；兩者都要額外標示「非官方」，亦令同一隻基金在不同頁面出現兩套口徑。積金局基金類型是官方、雙語、按股票比重細分混合資產，已足以支持同類比較。

## 後果

- 舊快照 payload 可能仍帶 `lipperCategory`／`classification`／`mappedAllocation`；API 一律不再輸出。`comparison_group_stats.avg_allocation`／`allocation_count` 欄位保留但寫入 NULL／0，不做 D1 migration。
- 混合資產按積金局股票比重區間分組；「未分類」類型（例如「混合資產基金 - 未分類混合資產基金」）照官方原文自成一組，不再細分。
- 基金解讀只剩十大持倉集中度及三年波幅兩項。

## 否決方案

- **保留三桶作「資產組成」而非「基金分類」**：使用者選擇全部移除。
- **用受託人自述的 `fundTypeDescriptor` 細分**：非標準文字，會變相建立新的編輯分類。

## 重審時機

積金局平台更改基金類型清單（新增、改名、刪除）時：`assertMpfaFundTypes` 會令發布停下，先更新對照表及本 ADR。
