# ADR 0012 — 便覽官方文字欄位原文照錄

日期：2026-10-04
狀態：已接受（使用者要求基金頁一目了然地顯示投資目標、資產配置、基金特色、過去表現及最新投資方向；確認「基金特色」以官方事實及本站計算呈現，不撰寫賣點）

## 決定

基金便覽的文字欄位，只要契約聲明咗，就由便覽原文抽出並照錄：

| 欄位 | 便覽常見標題 | 網站用途 |
| --- | --- | --- |
| `investmentObjective` | 投資目標／Investment Objective(s) | 「投資目標」 |
| `managerCommentary` | 基金經理評論／Commentary／Manager's Commentary | 「最新投資方向」 |
| `marketForecast` | 市場預測／Market Forecast | 「最新投資方向」的受託人預測值 |
| `investmentManager` | 投資經理／Investment Manager | 「基金特色」的官方事實 |

1. **原文照錄**。唯一處理係版面空白：兩個中文字之間左右對齊撐開的空格刪走；英文跨行補一個空格；項目符號（•）開新段；重印做粗體效果的同一段文字只保留一份。唔刪句、唔摘要、唔改寫、唔翻譯、唔改任何數字。
2. **中英分開保存**（`zh`／`en`），按每行有冇中文字分開；只有一種語文就只存一種，唔由本站翻譯補齊。
3. **抽唔到就明講**，沿用 `unavailableFields`／`unavailableKinds`：
   - 搵唔到標題或者標題下冇文字 → `not-disclosed`。
   - 同一位置有兩段內容唔同的文字（疊印另一版） → `overlaid-text-layer`，整段唔出，唔出局部文字。
   - 官方有印，但版面令本站讀唔齊（續落下一頁、頁底改為中英並排） → `unreadable-layout`，整段唔出；
     網站講明「官方有披露，但本站未能完整讀取」，唔可以講成官方未提供。（2026-10-04 補充）
4. **每段保留自己的日期**。評論日期只在便覽明示時記入 `temporalScopes.commentary`（ADR 0008）；否則顯示便覽日期並標明「便覽日期」，唔沿用平台 `dataAsOf`。
5. **範圍要講明**。同一期便覽入面多隻基金一字不差共用的市場評論唔可以當成某一隻基金的評論，頁面要標明屬計劃整體的市場評論；逐隻基金一份便覽（富達、強積金集成信託）跨份計。只印一次、唔屬任何一隻基金的計劃層面評論（中銀保誠附錄、海通首頁）需要時另設計劃層面欄位。
6. **基金特色唔係賣點**。「基金特色」只由兩類內容組成：官方事實（投資經理、成立日期、規模、基金類型描述、是否追蹤指數及基準指數）；同一積金局基金類型內的位置（費用、規模、波幅），標明「本站計算」及計算規則。網站唔撰寫推銷字眼，亦唔顯示「推薦」。

## 原因

使用者想喺網站一頁睇晒基金的投資目標、投資方向及特色。這些內容官方已經用文字披露；本站的價值在於集中、標日期、可追溯，而唔係再寫一次。摘要或改寫會引入本站的判斷，等同紅線 1（改寫官方內容）同紅線 6（編輯判斷要標明）要處理的風險；照錄原文就唔使逐句覆核本站有冇講錯。

## 後果

- 每個受託人便覽要逐份寫契約欄位（標題、欄界、結束標記、空隙上限），同配置／持倉一樣按計劃逐份擴展；未寫契約的計劃，網站顯示「未取得」，唔係「官方未提供」。
- 評論每季更新，便覽比平台落後四至八個月；頁面要顯示評論的日期及距今時間。
- 便覽受託人版優先（ADR 0003）。積金局副本的永明彩虹計劃把兩至三版疊印在同一頁，文字欄位只可以用受託人版。

## 否決方案

- **AI 摘要或改寫評論**：引入本站判斷，而且難以逐句核對；使用者要求官方資料。
- **由本站撰寫「賣點」**：屬推銷，違反中立比較的定位。
- **只存英文或只存中文**：便覽係雙語官方文件，兩種語文都係原文。

## 重審時機

受託人改版令契約失效（覆蓋報告見到 `not-disclosed` 大量增加）；或者積金局推出結構化的基金資料（例如投資目標欄位）可直接取代便覽抽取時。
