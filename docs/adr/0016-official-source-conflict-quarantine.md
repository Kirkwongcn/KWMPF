# ADR 0016 — 官方來源互相衝突時隔離衝突行，記錄兩個官方數字（提案）

日期：2026-10-17
狀態：**提案（待使用者批准；實作見 draft PR，未合併）**

## 背景

issue #396：宏利環球精選《每月摘要》2026-09-30 期，29 行得一次交叉核對失敗——`mpfa-cf-365`（DHK121 利息基金，公佈利率型保證基金，單一班別）5 年受託人印 `3.69`、積金局平台 `3.72`；10 年受託人 `5.71`、平台 `5.78`（兩邊 `dataAsOf` 同為 2026-09-30）。該行一年（0.88）、全部五個曆年數字同平台完全一致；欄位對齊經 `pdftotext -bbox`、pdfminer、pdfplumber 三次獨立閱讀核實，印住的數字就係 3.69／5.71（證據見 issue 留言及 `KWMPF-6H/impact.md`）。即兩個官方來源本身唔一致。

現行規則（ADR 0014／紅線 3）以文件為單位：任何一行對唔上，成份作廢。結果係得一行衝突，29 隻基金嘅三年累積全部無法更新到 2026-09-30，一路停在 2026-08-31，並且冇任何地方記錄到兩個官方數字各自嘅存在。宏利註腳只講到「利息基金表現以公布利率按月複式計算」同公布過去 12 個月利率；積金局無公開計算方法文檔（見 `KWMPF-6H/research.md`）——喺兩邊都係官方口徑、機制未能確認嘅情況下，點樣處理？

## 選項

A. **加容差**（例如 ≤0.05 視為一致）：否決。嚴格等值係紅線 1 嘅執行機制；容差等於隱性當平台數字係啱嘅（或者受託人係啱嘅），即冇記錄、冇查詢嘅靜默取態。要改必須另行 change-policy／ADR 討論。
B. **維持整份作廢**（現狀）：安全，但每次衝突都令成個計劃嘅三年數字滯後；兩個官方數字得一個存檔喺 rejected 報告一句說話入面，冇登記、冇跟進結構。
C. **行級隔離 + 官方衝突登記**（建議）：見下面決定。

## 決定（提案）

1. **分類失敗原因，縮小作廢單位**：
   - 結構性失敗（讀唔到表、欄格數量唔啱、名稱配對失敗、同一類別兩行、計劃基金缺行）或者**一年核對失敗／缺同期一年**照舊成份文件作廢——呢啲代表可能讀錯欄或者類別對調，紅線 3 語義不變。
   - 一行一年核對通過，而 5 年／10 年累積同平台同期（`dataAsOf` 相同）嚴格比較唔等——定義為**官方來源衝突**，只隔離嗰一行。
2. **隔離行唔出任何紀錄**：該基金連三年數字都唔發布新一期（三個年期出自同一條受託人內部序列，衝突未排除之前全部唔用）；繼續顯示上一期已核實嘅值連自身日期，按 90 日時效規則標過期。唔會由第三方（Lipper）補位——ADR 0015 受託人優先，受託人明明有披露，換用 Lipper 數字係變相揀邊。呢條防線由代碼強制：本次運行被隔離嘅基金，其 `--hkifa` Lipper 行一併剔走並記入報告 `thirdPartySuppressedForConflicts`（唔靠人記）。
3. **衝突登記表**：報告檔新增 `officialConflicts`，逐條記錄 `schemeName`、`fundClassId`、`label`、年期、受託人解析值連印出原文 `trusteePrinted`（讀者資料源冇格原文時為 `null`＝未能確認，唔可以用序列化數字頂替原文，紅線 1）、受託人 `dataAsOf`、平台值連平台 `dataAsOf`、受託人文件 `sourceUrl`／`sourceSha256`（平台方來源以報告頭部 `sourceSnapshot` 為準）。照錄，唔平均、唔揀邊、唔改寫（紅線 1、7）。登記表屬資料產品，唔涉及編輯分類（紅線 6）。**整份作廢都唔可以丟失登記**：結構性／一年失敗擲出作廢時，擲出前已登記嘅長年期衝突隨錯誤物件（`DocumentRejectedError`）交返出嚟，CLI 照記入登記表，數字亦嵌入 reject 原因文字（`rejectedSources.reason` 照錄）。
4. **文件狀態**：有衝突行嘅文件照用其餘行產生候選；報告記錄 `quarantinedRows`。若全部行都隔離，視同整份作廢（全部披露可疑）。工作流程層面，衝突行唔再算 parser 故障，跟進 issue 應標明「官方來源衝突」並附登記表內容，向積金局（5/10 年 cumulative 對保證基金嘅窗口、按月結息、捨入口徑）同受託人（內部序列）查詢，回覆補入登記。
5. **紅線對照**：紅線 1——兩個數字逐個原文記錄，冇取態；紅線 2——衝突登記唔涉及 `n.a.`；紅線 3——「一行對唔上整塊當官方未提供」保留於結構性／一年失敗；長年期官方衝突嘅「塊」經本 ADR 重新界定為該一行（呢個係對紅線 3 應用範圍嘅修改，故須本 ADR 明示並由使用者批准）；紅線 4——比較仍然嚴格等值，無模糊；紅線 5——隔離行唔借用任何其他基金、類別或第三方數字；紅線 6——無新增編輯數值；紅線 7——兩個數字各自保留日期，頁面沿用各自截至日期。
6. **重審條件**：積金局或受託人公開解釋計算口徑後，若其中一方可被證明為口徑基準，另行 ADR 決定係否恢復單一口徑發布；若多個受託人出現同類衝突（登記表 ≥3 宗），重審本方案。

## 後果

- 宏利 2026-09-30 期：28 行照常產生三年累積候選；`mpfa-cf-365` 保留 2026-08-31 嘅 `2.66` 並登記衝突（3.69@2026-09-30 vs 3.72@2026-09-30；5.71@2026-09-30 vs 5.78@2026-09-30）。
- 代碼：交叉核對由 CLI script 抽成可測試模組（純重構，語義如上）；報告檔結構新增 `officialConflicts`；`rejectedSources` 語義收窄至結構性／一年失敗。
- 風險：若衝突其實係類別對調而一年恰好啱（ADR 0014 引入長年期核對嘅初衷），隔離行會漏報一個錯配類別嘅三年數字。緩衝：一年照舊硬性核對、同名多於一個類別即整份作廢、隔離行本身唔發布任何新數字——漏報嘅後果只係該基金維持舊值，唔會發布錯值。
