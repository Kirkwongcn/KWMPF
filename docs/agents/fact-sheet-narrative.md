# 便覽官方文字欄位：投資目標、評論、市場預測

決定及原因見 ADR 0012；配置及十大持倉的抽取見 `fact-sheet-extraction.md`，兩者共用同一份契約及區段切法。

`packages/coverage/src/fact-sheet-narrative.ts` 按契約的 `narrative` 讀投資目標、基金經理評論、
市場預測及投資經理（ADR 0012）。同配置一樣，契約只講去邊度攞：

- `heading` 認中英兩段標題，取最上嗰段做錨點；`band` 一律寫明欄界，文字欄唔靠自動推斷。
- 結束靠 `stopAt`（下一塊披露的標題，例如滙豐的「基金資料」「累積回報」表頭）、同區段其他欄位的
  標題，或者 `maxGap`（正文行距約 10 pt；隔咗一大段空白之後係通告或註腳，例如滙豐環球股票基金
  評論欄下面的合併通告）。`minFontSize` 剔走上標註腳編號。字級逐隻基金唔同（滙豐 8 至 11 級），
  所以唔用固定上限分正文。
- 原文照錄：只刪兩個中文字之間的排版空格、英文跨行補空格、項目符號開新段、重印粗體只留一份。
  按每行有冇中文字分 `zh`／`en`。
- 同一位置兩段內容唔同（兩段都多過兩個字；全形標點的字框重疊唔算）就當疊印，整段走
  `unavailableFields`（`overlaid-text-layer`）；搵唔到標題或標題下冇字走 `not-disclosed`。

2026-10-04 滙豐強積金智選計劃 20 隻基金的投資目標及評論全部抽到。永明受託人版有市場預測及
投資經理欄，要等 `www.sunlife.com.hk` 開放先寫契約：積金局副本 MT00067 同一頁疊印咗兩至三版
（例如第 22 頁有香港股票、保守、環球低碳三隻基金，日期 2025-09-30 至 2025-12-31），文字欄位唔可以用。

### 版面原語（續）

- `columns`：中英兩欄並排（東亞評論左英右中，兩欄的行喺同一高度）就逐欄讀、逐欄計 `stopAt`／`maxGap`，
  再按欄次序接駁；唔分欄會把同一高度的中英兩行併成一行。
- `minDepth`：正文由標題下若干 pt 先開始。東亞 DIS 基金的十大持倉表延伸到評論標題右邊。
- 法定字句唔屬評論：東亞 DIS 基金評論之後的「年度回報與參考投資組合的重大差異理由」用 `stopAt` 截斷。
- **共用評論**：同一份便覽多隻基金同一欄位一字不差，抽取層記低 `sharedAcrossFunds`（包括本基金的隻數），
  網站標明「屬計劃整體的市場評論，並非這隻基金專屬」。只比對原文，唔做相似度判斷——差一個空格就當兩段。
