# 香港強積金比較網站：第一版產品規格

## Problem Statement

香港強積金計劃及基金資料分散於不同官方文件、受託人網站及第三方資料服務。一般打工仔難以按自己的投資年期、風險取向、基金類別及資產配置作出有系統的比較；有投資經驗人士需要更深入的回報、風險、費用及持倉分析；僱主及 HR 則需要比較不同計劃的基金選擇及投資風險。

## Solution

建立一個免費、無廣告、繁體中文優先的香港強積金資料導航及比較工具。第一版涵蓋所有現行可供選擇的強積金計劃、成分基金及預設投資策略，以官方資料為主、可靠第三方資料作補充，目標每日更新並顯示資料來源及截至日期。

網站提供三項核心功能：按條件篩選及排名基金、比較強積金計劃、查看詳細基金資料。排名預設並列 1 年、3 年、5 年及 10 年時間框架，並支援自訂期間；排序重點依次為基金類別及資產配置、長期回報、風險程度。網站只提供資料比較及投資教育，不作個人化投資建議。

## User Stories

1. As a 一般打工仔, I want to 輸入年齡、投資年期及風險取向, so that 我可以找到值得進一步了解的基金類別。
2. As a 一般打工仔, I want to 按基金類別及資產配置查看排名, so that 我可以先理解基金投資什麼，再比較表現。
3. As a 一般打工仔, I want to 比較 1 年、3 年、5 年及 10 年回報, so that 我可以分辨短期及長期表現。
4. As a 一般打工仔, I want to 查看風險指標, so that 我不會只因回報較高而忽略波動。
5. As a 一般打工仔, I want to 看到每項數據的來源及截至日期, so that 我可以判斷資料是否足夠新及可信。
6. As a 一般打工仔, I want to 直接搜尋基金名稱、計劃或受託人, so that 我可以查找現有基金。
7. As a 一般打工仔, I want to 查看基金詳細頁, so that 我可以在同一頁了解基金類別、配置、回報、風險、費用及主要持倉。
8. As a 一般打工仔, I want to 知道排名是如何計算, so that 我不會把網站排序誤解為個人化推薦。
9. As a 投資經驗較豐富的用戶, I want to 自訂比較時間框架, so that 我可以按自己的研究方法分析基金。
10. As a 投資經驗較豐富的用戶, I want to 比較基金持倉、資產配置及地區／行業分布, so that 我可以理解基金之間的實際差異。
11. As a 投資經驗較豐富的用戶, I want to 同時查看費用、回報、風險及持倉, so that 我可以作出完整的資料分析。
12. As a 僱主或 HR, I want to 比較計劃可提供的基金選擇及風險, so that 我可以整理供內部評估的資料。
13. As a 僱主或 HR, I want to 查看計劃及基金的收費和行政資料, so that 我可以作初步的計劃比較。
14. As a 僱主或 HR, I want to 在計劃層級查看旗下基金, so that 我可以了解每個計劃的投資選擇廣度。
15. As a 所有用戶, I want to 使用手機及電腦完成比較, so that 我可以在不同情境下查閱資料。
16. As a 所有用戶, I want to 清楚知道資料是否過期、待核實或不足, so that 我可以正確理解比較結果的限制。

## Implementation Decisions

- 第一版以一般打工仔為主要入口，同時保留投資者及僱主／HR 的比較需求。
- 第一版只涵蓋現行可供選擇的計劃及基金；已停止接受新供款但仍有資產的歷史基金不在範圍內。
- 主要架構分界為「標準化基金資料 → 比較／排名引擎 → 網頁展示」。
- 原始資料層保存來源、文件日期、擷取時間及版本；標準化資料層統一基金名稱、類別、費用、回報期間及風險定義。
- 資料來源以積金局、受託人及基金官方文件為主，可靠第三方資料作補充；展示時必須標明來源類型。
- 目標更新頻率為每日。更新失敗或資料異常時，保留上一個已驗證版本，不靜默估算或替換。
- 排名不以單一「推薦分數」取代全部資訊；介面應分開展示基金類別／配置、回報及風險組別，並說明排序方法。
- 預設比較期間為 1 年、3 年、5 年及 10 年，並支援自訂期間；資料不足時顯示資料不足，不與完整期間資料作不當比較。
- 手機及電腦同等重要；簡單結論先行，詳細表格及分析按需展開。
- 第一版只提供資料比較及投資教育，不提供個人化投資建議、買賣指示或轉換指示。
- 第一版不包括觀察清單及 HR 報告生成；這些列為第二階段。

## Testing Decisions

- 測試應以外部可見行為為主：輸入條件後是否得到正確篩選結果、排序是否遵守選定指標、頁面是否顯示正確來源及截至日期。
- 標準化資料測試應涵蓋名稱對應、基金類別、資產配置、費用、回報期間、風險指標及資料不足情況。
- 排名引擎測試應驗證不同時間框架、排序方向、同分處理、缺失資料及異常數值處理。
- 更新流程測試應驗證成功更新、來源失效、資料格式變更、資料異常及回退上一個已驗證版本。
- 展示層測試應涵蓋手機及電腦版的核心流程，以及基金搜尋、計劃比較、詳細基金頁和來源顯示。
- 應加入來源可追溯性測試，確保任何展示數值都能連回其標準化資料及原始來源。
- 在未建立正式程式碼庫前，測試框架及既有測試慣例尚未指定；日後實作時應優先測試比較／排名引擎這個主要 seam。

## Out of Scope

- 個人化投資建議、基金買賣或轉換指示。
- 已停止接受新供款但仍有資產的歷史基金資料。
- 觀察清單、登入帳戶及個人投資組合追蹤。
- HR 報告自動生成及匯出。
- 英文版。
- 廣告、聯盟銷售、贊助排名及任何付費推薦。
- 即時市價、交易執行及保證未來回報。

## Further Notes

- 產品應在重要位置說明資料比較不等於投資建議，過往表現不代表未來結果，用戶應查閱受託人最新文件。
- 所有結果應顯示資料截至日期；「每日更新」是目標流程，不代表每個來源每日都有新資料。
- 這份規格只代表已確認的產品目標及第一版範圍，不授權開始技術實作。下一個獨立步驟應是確認資料字典及官方資料來源清單，再另行制定技術方案。
