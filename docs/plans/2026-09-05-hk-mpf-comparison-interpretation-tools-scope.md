# 香港強積金比較網站:計劃/基金比較與解讀工具規格(v1範圍)

## Context

承接 `2026-08-08-hk-mpf-comparison-product-spec.md` 訂立嘅產品目標(篩選排名、計劃比較、基金詳情三項核心功能),呢份文件將「比較」呢組功能進一步拆做三層,並定案邊層屬於 v1、邊層留返 v2。用語沿用 `KWMPF/CONTEXT.md`(強積金計劃、成分基金、比較組別等)。

## 三層比較架構

### 大:計劃整體對比

**v1 範圍**:受託人、基金選擇數目、預設投資策略(DIS)表現、收費範圍(FER)
**v2 範圍(不在 v1)**:行政評分——同 8 月 8 號已批准嘅 v1 實作規格衝突(該規格明文將「完整行政服務評分」列為 v1 範圍以外),且現時冇官方或恆常嘅強積金服務評分資料源,需另立評分方法論(評分維度、資料蒐集方式、更新頻率)先可以做,故降做 v2
- 顯示方式:表格逐項對比(詳細版)+ 雷達圖概覽(視覺化),兩者並存
- 同時比較上限:最多 4 個計劃

### 中:同類別基金比較

- 分組方法:沿用現有 Lipper 香港退休基金分類(即現行「比較組別」口徑,見 CONTEXT.md)
- 比較指標:回報(1/3/5/10 年)+ 風險(標準差)
- 資產配置不列入呢層對比,留返基金詳情頁展示
- 支援按單一指標排序(例如按 3 年回報由高至低)

### 小:基金特性/賣點解讀

**v1 範圍 —— 解讀工具(A)**
- 呈現方式:文字解讀為主,圖表輔助
- 解讀因素(3 項):資產配置差異、十大持倉集中度、波幅對比
- 期間選擇:1 年/3 年/5 年預設掣 + 自訂開始/結束月份;未揀之前預設顯示 1 年;用戶選定期間後觸發解讀
- 文字生成方式:規則式範本(用計算出嚟嘅數字差距套入預設句式),唔用 AI 即時生成——冇額外 API 成本,同現有系統一貫嘅「唔靠估算」原則一致

**v2 範圍(不在 v1)—— 宣傳 vs 事實對照(C)**
- 對照回報 + 風險 + 資產配置實際持倉三項
- 「基金公司形容」嘅文字來源:基金月刊(factsheet)投資策略/目標描述 + 銷售文件(KFS/product brochure)賣點描述,兩者交叉對照
- 現有系統(KWMPF)只有數字類資料(資產配置、十大持倉、波幅、Lipper 分類),未有呢類文字資料,需新增一步文字擷取先做到 C;因此開發量較大,排後到 v2

**不採用 —— 篩選(B)**:唔做

## Out of Scope(v1)

- C(宣傳 vs 事實對照)全個功能,包括新增嘅文字擷取步驟
- 「大」層嘅行政評分(方法論未定)
- 篩選功能(B)
- 「中」層嘅資產配置比較(留返基金詳情頁)
