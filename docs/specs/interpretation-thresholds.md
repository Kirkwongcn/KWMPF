## 實作契約

設定在 `packages/coverage/src/interpretation-thresholds.ts`，三項可分開修改。`interpretFund` 接收基金數值與 #240 凍結的 `ComparisonGroupStatsRow`，回傳固定中文句式、各項狀態及門檻版本。股票配置明示為編輯歸類。

差距按未取整數值判斷，僅容許浮點運算誤差；句內差距顯示最多兩位小數。門檻是百分點差距，不是相對百分比，也不是統計顯著性判斷。不得由「高／低」推論優劣、適合程度或回報原因。

組別或個別指標少於三個有效樣本時不比較；基金數值或平均缺失、非有限數字時顯示資料不足，零值則保留。呼叫端須提供同一快照及正確組別的已核實可比較數值，並負責日期、來源及非完全可比提示。

純函數模組沒有 AI 或網絡呼叫。`GET /fund-classes/:id/interpretation` 由同一發布快照讀取基金值及凍結的組別平均，再呼叫純函數；頁面展示屬後續工作，不改排名。

三項因素都是快照當期的組合及風險資料，並不隨 1／3／5 年回報期間改變。因此 API 不接受期間選擇；在尚未發布完整月度價格序列前，亦不會假裝支援自訂期間。日後若加入以回報為基礎的第四項解讀，才連同權威資料來源及完整月份驗證另行設計。
